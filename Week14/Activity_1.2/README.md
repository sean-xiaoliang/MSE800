# Hello Django — Activity_1.2

The whole app is one file: [app.py](app.py). It displays **"Welcome &lt;username&gt; to Django!"**

## Run

```bash
pip install -r requirements.txt
python app.py runserver
```

## Open

| URL | Output |
|-----|--------|
| http://127.0.0.1:8000/Sean/ | Welcome Sean to Django! |
| http://127.0.0.1:8000/Alice/ | Welcome Alice to Django! |
